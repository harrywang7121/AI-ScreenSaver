LunchTalk Saver — 产品/体验准备文档


1. 产品概述

在 Mac 上用“触发角”启动一个屏保形态的“AI 双人对话秀”。用户离开电脑去吃饭时触发屏保，屏幕上以聊天界面展示两个 AI 角色持续互发消息；用户回来退出屏保后，桌面会弹出一个小窗口，给出对话摘要 + 灵感点，帮助用户快速获得启发。

2. 用户体验流程
2.1 启动（离开去吃饭）

用户准备离开电脑（例如午饭）。

鼠标快速移动到屏幕左上角触发角。

屏幕进入 LunchTalk Saver（像屏保一样全屏显示）。

2.2 运行（用户不在电脑前）

屏幕展示一个全屏“聊天界面”。

两个 AI 角色（左/右）持续互相发送消息，聊天记录不断增长。

用户无需任何操作，屏保以“自动播放”的方式运行。
4.（可选）屏幕一侧同步展示“实时摘要/灵感点”，随着对话更新。

2.3 结束（用户回来）

用户移动鼠标或按键退出屏保，回到桌面。

companion app 自动弹出一个小窗口：

展示本次对话摘要（精简、可一眼读完）

提炼 2–5 条“灵感点/可行动点”

可选提供“打开完整对话”的入口

3. 屏保界面形式（全屏）
3.1 主体：双人聊天 UI

视觉形式：类似 iMessage/WhatsApp 的对话界面

左侧 AI 角色 A：左对齐气泡

右侧 AI 角色 B：右对齐气泡

气泡交替出现，形成连续对话

对话内容在屏幕内可滚动呈现（用户回来能看到上面聊了什么）

角色区分：头像/名字/颜色/风格标签（可简洁）

3.2 辅助信息（可选但推荐）

右侧或底部一个Summary 区域（不打扰阅读，但可一眼扫到）：

“当前讨论主题”

“实时总结（3–7 条 bullet）”

“灵感点（2–5 条）”

轻量状态提示（例如：对话频率、更新时间、session 时长）

3.3 内容风格（默认）

短句为主、节奏轻快

两个角色分工不同：一个更发散、一个更落地（用户更容易读出价值）

避免无意义寒暄/重复

4. 退出后的“摘要弹窗”界面（桌面小窗口）
4.1 弹窗内容结构

标题：本次 session 名称（例如“午休对话 · 12:03–12:46”）

模块 1：一句话总览（可选）

模块 2：摘要 bullets（3–7 条）

模块 3：灵感点 / 可行动点（2–5 条）

模块 4：最近 3–5 条高亮金句（可选）

4.2 弹窗交互（尽量克制）

关闭（X）

复制摘要（Copy）

打开完整对话（Open Transcript）
-（可选）收藏本次 session

5. 必备功能清单（不含技术实现）
5.1 屏保体验相关

触发角启动屏保（由系统触发角行为进入）

屏保全屏展示双人对话

对话持续生成并累积为可回看的记录
-（可选）实时摘要/灵感点区域同步更新

屏保停止时，触发“摘要弹窗”

5.2 对话内容与控制

双角色持续互发消息（自动）

话题来源：

用户自定义话题列表（种子 topics）

或“自动推荐话题”（基于兴趣标签/随机探索）

session 概念：

每次启动屏保视为一次 session

session 有自己的对话记录与摘要

5.3 companion app 的基础存在感

常驻/后台运行（保证屏保时能生成对话、结束能弹窗）

提供设置入口

提供“查看历史 session / 完整对话”的入口（简单列表即可）

6. 设置项（用户可配置）
6.1 对话节奏

对话频率：X 秒/句（例如 6–20 秒可调）

是否在屏保内显示实时摘要（开关）

是否退出屏保后弹摘要窗口（开关）

弹窗自动消失时间（可选：不自动/10s/30s）

6.2 模型与成本控制

模型来源（Provider 类型）：

自定义 API Endpoint（例如 OpenAI-compatible）

Model name（下拉/输入）

API Key（用户输入）

Token 上限：

单次输出上限（max output）

上下文上限（context budget）

成本提示（可选）：估算本次 session 的 tokens 或费用（开关）

6.3 话题与风格

话题种子（多行文本/列表）

兴趣标签（简单勾选：AI/产品/硬件/投资/随便聊…）

对话风格：

更发散 / 更落地（滑杆）

更短 / 更长（滑杆）

角色设定（可选）：

角色 A/B 的名字

角色性格模板（例如“批判型”“教练型”“研究型”）

6.4 历史与隐私

保留历史 session 的数量/天数

一键清空历史

是否本地保存完整对话（开关：仅摘要 / 摘要+全文）

7. 成功标准（体验层面的验收）

用户只用触发角就能进入屏保形态的对话界面

用户离开期间对话持续进行且可回看

用户回来退出屏保后，第一眼能在弹窗里拿到清晰摘要与灵感点
